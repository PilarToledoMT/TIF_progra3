# Harmony Hub

Un proyecto web desarrollado con **React**, **Vite** y **JavaScript**, configurado con **ESLint** para mantener un código limpio y estructurado.

---

## 🚀 Tecnologías Utilizadas

* **Frontend:** React, JavaScript (ES6+)
* **Build Tool:** Vite
* **Linter / Formateo:** ESLint
* **Assets / Estilos:** CSS3, HTML5

---

## 🛠️ Instalación y Configuración

Sigue estos pasos para ejecutar el proyecto de forma local:

1. **Clonar el repositorio:**
   ```bash
   git clone <URL_DEL_REPOSITO>
   cd TIF_progra3-main

2. **Instalar dependencias:**
   ```bash
   npm install

3. **Ejecutar el servidor de desarrollo:**
   ```bash
   npm run dev
Abre la dirección que indique Vite (generalmente http://localhost:5173) en tu navegador.

---

## 📜 Scripts Disponibles
En el archivo package.json puedes encontrar y ejecutar los siguientes comandos:
* npm run dev - Inicia el servidor de desarrollo local con recarga rápida (HMR).
* npm run build - Compila la aplicación para producción en la carpeta dist.
* npm run lint - Ejecuta ESLint para analizar y reportar errores en el código.
* npm run preview - Permite previsualizar localmente la build de producción.

## 📁 Estructura del Proyecto

```text

```
